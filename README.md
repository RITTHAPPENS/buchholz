# Ingenieurbüro Buchholz GmbH - Website

Statische Website ohne CMS, ohne Cookies und ohne externe Ressourcen.

## Aufbau

- `index.html` - Startseite
- `assets/styles/` - Stylesheet
- `assets/scripts/` - JavaScript (Navigation)
- `assets/fonts/` - Schrift Readex Pro, lokal eingebunden
- `assets/images/` - Bilder als WebP in mehreren Größen, Icons als SVG-Sprite

## Veröffentlichen

Den kompletten Ordnerinhalt per FTP/SFTP in das Web-Verzeichnis des Webspaces hochladen.
